<h1>Amigo Secreto</h1>

Proyecto del curso de Alura Latam, desarrollado en JavaScript, HTML y CSS.  
La aplicación permite agregar nombres a una lista y luego realizar un sorteo para elegir un amigo secreto de forma aleatoria.

FUNCIONALIDADES

- Agregar nombres a la lista de amigos.
- Validar que los nombres no estén vacíos, no contengan símbolos ni números.
- Evitar nombres duplicados.
- Visualizar la lista actualizada de amigos en pantalla.
- Realizar el sorteo de un amigo secreto de forma aleatoria.
- Requerir al menos dos participantes para el sorteo.
- Permitir presionar botón Enter para agregar un nombre.

TECNOLOGÍAS USADAS

- HTML: estructura de la aplicación.
- CSS: estilos básicos.
- JavaScript: lógica del proyecto.

INSTALACIÓN / USO
1. Clonar el repositorio:
   ```bash
   git clone https://github.com/Leandro-DC/amigo-secreto.git

2. Abrir el archivo index.html en tu navegador.

3. Ingresar nombres en el campo de texto y presionar Enter o el botón Agregar.

4. Una vez cargados los nombres, hacer clic en Sortear amigo.
